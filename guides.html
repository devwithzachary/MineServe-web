Quick Start Guides

MineServe · Android, Linux, macOS (Beta), Windows (Beta) & Docker · Full USER_GUIDE.md on GitHub

1. Rootless Android Setup

MineServe runs an isolated Ubuntu userspace inside PRoot with zero root permissions required.

  • Install from Google Play, F-Droid, or GitHub Releases (-release.apk).
  • On first launch, MineServe downloads the Ubuntu rootfs and OpenJDK 21 automatically (or lets you import a local .tar.gz archive).
  • Set Android Battery Usage to Unrestricted so background worlds stay online, and use the 2-step wizard to create your server.

2. Linux Desktop, Headless :8080 & APT/RPM Repos

Install the native Linux package (.deb, .pkg.tar.zst, or portable bundle) in one command:

# Desktop GUI + CLI
curl -fsSL https://mineserve.app/install.sh | bash

# Headless systemd service on port 8080
curl -fsSL https://mineserve.app/install.sh | bash -s -- --headless

# Rootless user install (~/.local/opt/mineserve)
curl -fsSL https://mineserve.app/install.sh | bash -s -- --user

Signed APT & RPM Repositories (v1.9.0+)

# Debian / Ubuntu (APT)
curl -fsSL https://mineserve.app/apt/mineserve-archive-keyring.gpg | sudo tee /usr/share/keyrings/mineserve-archive-keyring.gpg >/dev/null
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/mineserve-archive-keyring.gpg] https://mineserve.app/apt stable main" | sudo tee /etc/apt/sources.list.d/mineserve.list >/dev/null
sudo apt-get update && sudo apt-get install mineserve

# Fedora / RHEL (DNF)
sudo curl -fsSL https://mineserve.app/rpm/mineserve.repo -o /etc/yum.repos.d/mineserve.repo
sudo dnf install mineserve

Useful CLI Flags

mineserve --headless --port 8080 --bind 0.0.0.0
mineserve --reset-admin

3. macOS Beta (Apple Silicon & Intel)

  • Download MineServe-<ver>-macos-arm64.dmg (Apple Silicon) or MineServe-<ver>-macos-x64.dmg (Intel) from GitHub Releases and drag MineServe.app to /Applications.
  • Gatekeeper (Beta): Official Apple Developer ID notarization arrives in v2.0.0. Until then, allow the app in System Settings -> Privacy & Security -> Open Anyway or run:
xattr -dr com.apple.quarantine /Applications/MineServe.app
/Applications/MineServe.app/Contents/MacOS/MineServe --headless
  • For Bedrock players on macOS, choose Bedrock (Geyser) (Paper + GeyserMC) because Mojang does not publish a native macOS Bedrock Dedicated binary.

4. Windows Beta (x64)

  • Install via MineServe-<ver>-windows-x64.msi (recommended), .exe, or extract the portable .zip and run bin\mineserve.bat (pass --headless for WebUI-only mode).
  • Install via Winget: winget install DevWithZachary.MineServe.
  • SmartScreen (Beta): Official SignPath Foundation code signing arrives in v2.0.0. Click More info -> Run anyway if prompted.

6. Tunnels, Modpacks, Backups & Proxies

Every server supports local LAN play, automatic UPnP/NAT-PMP router forwarding, and free bore.pub / Playit.gg tunnels that work behind CGNAT and mobile networks.

  • Networking: Open Management -> Public Multiplayer Tunneling to enable Bore, Playit.gg, UPnP, or optional MineServe Cloud vanity domains (*.play.mineserve.app / *.playms.uk + remote *.panel.mineserve.app Web Admin).
  • .mrpack Filtering: Import Modrinth .mrpack archives; client-only mods are automatically disabled as .jar.disabled so dedicated servers boot cleanly.
  • Off-Device Backups: Sync .zip snapshots to Nextcloud/WebDAV (with Test Connection & auto-sync), Android SAF folders, or encrypted Cloudflare R2 in MineServe Cloud.

7. Java + Bedrock Cross-Play (GeyserMC)

Let PC (Java Edition) and console, mobile, or Windows Bedrock players join the same world with zero manual plugin wiring:

  • In the 2-step Create Server wizard, pick Bedrock (Geyser). MineServe installs PaperMC, GeyserMC, and Floodgate together automatically.
  • Java players connect on TCP port 25565, while Bedrock players connect on UDP port 19132.
  • Bedrock friends do not need a Java Edition account when Floodgate is enabled.
  • For public play behind CGNAT, use Playit.gg or MineServe Pro (simultaneous Java TCP + Bedrock UDP relays).
